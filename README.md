# 🎓 Student Record Management System

## 📌 Description

A **console-based CRUD system** to manage student records using Java.

---

## 🎯 Features

* ➕ Add student
* 👀 View students
* ✏️ Update student
* ❌ Delete student

---

## 🛠️ Technologies Used

* Java (JDK)
* ArrayList (Collections)
* VS Code / IntelliJ

---

## ▶️ How to Run

```bash
javac StudentManagement.java
java StudentManagement
```
